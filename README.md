# NOVA Finder

Shopify + Razorpay site discovery bot for Telegram.

## Setup

1. Create a bot with @BotFather → get token
2. Get your Telegram user ID (from @userinfobot)
3. Set env vars:
   - `FINDER_BOT_TOKEN` — bot token
   - `FINDER_ADMINS` — your user ID
4. Install:
   ```bash
   pip install -r requirements.txt
